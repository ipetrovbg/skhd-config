#### `skhd` stops working
1. Navigate to System Settings → Privacy & Security → Device
  Control and Data Access and remove `skhd` from the list.
2. Run `skhd --restart-service` in the terminal.
3. Allow `skhd` access in System Settings → Privacy & Security → Device
  Control and Data Access.

There are times when a full system restart is needed.
Sometimes the popup window is below all other windows.
